# JavaScript Reference

I'm using this folder to keep track of JavaScript as I study it: short notes, working examples, and mini projects.

I try to answer three questions for each topic: **What does it do? When would I use it? Can I write a small example myself?**

## Topics

| Section | What I'm practicing |
| --- | --- |
| [01 — Fundamentals](./01-Fundamentals/) | Variables, types, operators, strings, conditions |
| [02 — Control Flow and Data](./02-Control-Flow-and-Data/) | Loops, functions, arrays, objects, iteration |
| [03 — Advanced Core](./03-Advanced-Core/) | Scope, closures, `this`, errors |
| [04 — Browser](./04-Browser/) | DOM and events |
| [05 — Async and APIs](./05-Async-and-APIs/) | Promises, `async/await`, `fetch`, modern syntax |
| [06 — Modules](./06-Modules/) | Splitting JavaScript into reusable files |
| [Mini Projects](./projects/) | Small exercises that put the topics together |

## How to use this reference

1. Pick a topic and read its `README.md`.
2. Run the example, then change something in the code.
3. Try the practice question before checking another solution.
4. Build a small project with what I've learned.

## Running the examples

Install [Node.js](https://nodejs.org/) (version 20+ recommended) and open the repository in VS Code.

For terminal examples, run a `.js` file:

```bash
node JavaScript-reference/02-Control-Flow-and-Data/08-Loops/example.js
node JavaScript-reference/03-Advanced-Core/15-Closures/example.js
node JavaScript-reference/05-Async-and-APIs/22-Modern-Syntax/example.js
node JavaScript-reference/06-Modules/23-Modules/main.js
```

For browser examples, open the `index.html` file in that folder. The `fetch` example requires an internet connection.
