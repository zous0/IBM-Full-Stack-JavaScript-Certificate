# 06 — JavaScript Modules

A module is a JavaScript file that **exports** code for other files to **import**. It helps me avoid putting everything in one huge file.

| Topic | Example |
| --- | --- |
| [23 — Modules](./23-Modules/) | Separate product data, a helper function, and the main program |

## Try it

From the repository root, run:

```bash
node JavaScript-reference/06-Modules/23-Modules/main.js
```

This example uses ES modules (`import` / `export`). The `package.json` inside the lesson tells Node to treat `.js` files as modules.
