# Practice — Loops

Try these in a new file before opening `example.js` again.

1. Use a `for` loop to print the numbers **1 through 5**.
2. Use a `while` loop to print a countdown **3, 2, 1**. Make sure it stops.
3. Use a `for` loop to print **1, 3, 5** from the numbers 1–6 using `continue`; stop as soon as the counter reaches 6 with `break`.

**Debug challenge:** What's wrong with this loop?

```js
let number = 1;
while (number <= 5) {
  console.log(number);
}
```

**Hint:** Which variable needs to change so the condition becomes false?
