# Arrays

An array is a list of values. It's useful for things like tasks, products, or scores.

```js
const tasks = ['Study', 'Gym'];
tasks.push('Read');
console.log(tasks[0]); // Study
```

Array indexes start at `0`. `push()` and `pop()` change the original array; `slice()` makes a copy of part of it.

I use an object instead when I need to describe one item with named properties, like a product's name and price.
