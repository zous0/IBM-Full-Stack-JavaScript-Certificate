# Product-data mini project

This is a small Node.js script that works with a list of products. There's no website or API involved; the data is written directly in the file.

It can:

1. List the products.
2. Show products over $500.
3. Get just the product names.
4. Find a product by name.
5. Add up the prices.
6. Check if any product costs over $900.

I made this to practice arrays, objects, functions, loops, and methods like `filter()` and `find()`. It's a useful starting point for product search in a larger app.

From the repository root:

```bash
node javascript/02-control-flow-and-data/mini-project/product-data.js
```

**Try changing:** add another product, adjust the price limit, or search for a product that doesn't exist.
