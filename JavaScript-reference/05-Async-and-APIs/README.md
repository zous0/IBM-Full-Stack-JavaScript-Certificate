# 05 — Async JavaScript and APIs

This part is about working with things that don't finish immediately, like loading data from a server.

| Topic | What I use it for | Example |
| --- | --- | --- |
| [20 — Async JavaScript](./20-Async-JavaScript/) | Promises and `async/await` | `example.js` |
| [21 — APIs and HTTP](./21-APIs-and-HTTP/) | `fetch`, JSON, status codes, errors | `get-tasks.js` |
| [22 — Modern Syntax](./22-Modern-Syntax/) | Cleaner JS with destructuring, spread, and `?.` | `example.js` |

## Run

Use **Node.js 20 or newer** for these examples (Node 18 also supports `fetch`).

```bash
node JavaScript-reference/05-Async-and-APIs/20-Async-JavaScript/example.js
node JavaScript-reference/05-Async-and-APIs/21-APIs-and-HTTP/get-tasks.js
node JavaScript-reference/05-Async-and-APIs/22-Modern-Syntax/example.js
```

The API example needs an internet connection. The others work offline.
