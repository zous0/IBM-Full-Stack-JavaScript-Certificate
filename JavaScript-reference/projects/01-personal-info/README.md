# 01 — Personal Info / Form Input Practice

A small terminal example that simulates form data. Real HTML inputs usually give me strings, even for numbers. Here I clean the data before using it.

**What it practices:** `.trim()`, `Number()`, `parseFloat()`, conditions, and template strings.

Run from this folder:

```bash
node app.js
```

**Try changing:** `age` to `"17"`, or `quantity` to `"0"`. See how the output changes.

This is a practice script, not a form with actual HTML input fields.
