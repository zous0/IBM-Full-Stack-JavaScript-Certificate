# 03 — Product Search App

A simple browser app to practice **searching, filtering, and sorting** products. It's plain HTML, CSS, and JavaScript — no React or backend yet.

## Features

- Search products by name
- Filter by category
- Sort by price
- See a helpful message when nothing matches

## Run it

Open [index.html](./index.html) in your browser (or use VS Code Live Server). There's nothing to install.

## Files

- `index.html` — page structure
- `style.css` — basic styles
- `app.js` — product data and filtering logic

## What I want to improve later

- Add a product details view
- Load products from an API instead of a hard-coded array

This is a practice app with sample data, not a real store.
