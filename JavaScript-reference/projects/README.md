# JavaScript Mini Projects

I use small projects to practice the topics instead of only reading about them. Each project is intentionally simple and uses plain JavaScript.

| Project | What it practices | How to run |
| --- | --- | --- |
| [01 — Personal Info](./01-personal-info/) | Variables, strings, numbers, conditions | Node.js |
| [02 — Product Data](./02-product-data/) | Arrays, objects, methods, functions | Node.js |
| [03 — Product Search App](./03-product-search-app/) | DOM, events, filtering, sorting | Browser |

No frameworks or npm install required.

**What I'm working toward:** Build enough small projects that I can explain every part of the code without looking it up.
