# 02 — Product Data Practice

A small product-list script that uses arrays of objects. I use functions to work with the data instead of repeating code.

**What it practices:** Objects, `filter()`, `map()`, `reduce()`, and `for...of`.

Run from this folder:

```bash
node app.js
```

**Try changing:** Add a new product to the array and check how the results change.

This is the same product-data exercise from `02-Control-Flow-and-Data`, collected here so it's easy to find with the other projects.
