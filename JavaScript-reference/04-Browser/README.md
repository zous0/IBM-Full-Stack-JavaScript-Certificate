# 04 — JavaScript in the Browser

Node.js runs JavaScript in the terminal. A browser can also run JavaScript, and it gives us the **DOM** so we can change a webpage.

## Run the demos

Open an `index.html` file in your browser, or use the VS Code Live Server extension. No Node.js or packages needed.

A reminder for myself: use `textContent` for plain text. I don't need `innerHTML` just to display user input.
